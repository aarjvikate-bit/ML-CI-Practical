# ML Continuous Integration Project

## Objective
To automate the build and testing process of a machine learning application using GitHub Actions.

## Tools Used
- GitHub and GitHub Actions
- Python 3.11
- scikit-learn
- pytest
- joblib

## CI Workflow
1. Checkout the repository.
2. Set up Python and install dependencies.
3. Train the machine learning model.
4. Run automated test cases.
5. Display the build report.
6. Upload the build report and model as artifacts.

## Result
The CI workflow successfully automates machine learning model training, testing, and artifact generation using GitHub Actions.
